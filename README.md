# VTT Whisper Processor
[![DOI](https://zenodo.org/badge/1078945285.svg)](https://doi.org/10.5281/zenodo.17387490)

This repository provides a Python script, `python-vtt.py`, for processing VTT files generated by [whisper.cpp](https://github.com/ggml-org/whisper.cpp). Its main goal is to make transcription files easier to read and work with, especially during the open coding phase of a Grounded Theory Analysis.

## Purpose

The script processes a VTT subtitle file by:

* **Thinning subtitles:** keeps only every 30th timestamp entry.
* **Fixing capitalization:** converts words to lowercase unless they meet specific criteria.

A word remains capitalized if:

* It's in the exceptions list: `Android, iOS, Google, Apple`
* It starts a paragraph
* It follows sentence-ending punctuation: `. ! ?`

The script preserves:

* Empty lines
* WebVTT metadata
* Timestamp lines (`HH:MM:SS`)

## Usage

```bash
python3 python-vtt.py input.vtt output.vtt
```

Outputs:

* `output.vtt`: thinned subtitles
* `output.vtt_case_fixed.vtt`: thinned + capitalization fixed

## Prerequisites

* Python 3 installed

## Notes on `whisper.cpp` and `ffmpeg`

This script processes VTT files generated by `whisper.cpp`. To learn how to use `whisper.cpp`, see the [official documentation](https://github.com/ggml-org/whisper.cpp/blob/master/README.md).

You’ll need **CMake** to build `whisper.cpp` before using it.

### Example workflow with shell scripts
Examples were created based on whisper.cpp version v1.7.4

Step 1: Convert MP4 video file to MP3 audio file

```bash
ffmpeg -i file-name.mp4 -q:a 0 -map a file-name.mp3
```

Step 2: Convert MP3 audio files to WAV audio file**

```bash
mkdir -p output
for i in ./data/*; do
  f="${i##*/}"
  filename="${f%.*}"
  ffmpeg -i "$i" -acodec pcm_s16le -ac 1 -ar 16000 "./output/$filename.wav"
done
```

Step 3: Generate VTT transcription from WAV files

Model used: `large-v3-turbo`

```bash
for i in output/*.wav; do
  ./build/bin/whisper-cli -m ./models/ggml-large-v3-turbo.bin -l pt --output-vtt -f "$i"
done
```

After this, you'll have the vtt files, and can use the python script from this repo to process them.
